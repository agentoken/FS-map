# 城市分布地图 · 飞书多维表格仪表盘插件

统计多维表格中「城市」字段的内容，把城市归并到所属省份，在中国地图上按出现次数分级填色：
**0 次为灰色，次数最多的省份为红色，中间按次数分级渐变**。

## 功能

- 选择数据表 + 城市字段（文本/单选，一个单元格一个城市）
- 支持「全部数据」或「指定视图」作为数据范围
- 自动把城市名归并到省级行政区（788 条城市 → 省份映射，支持「杭州」「杭州市」「杭州市西湖区」等写法）
- 地图分级填色 + 图例 + 悬浮提示（显示该省次数与 Top 城市明细）
- 配置态实时预览、展示态监听数据变更自动刷新
- 无法识别的城市名会在配置面板提示数量，不计入地图

### 1. 地图边界：`src/assets/china-geo.json`

| 项目 | 说明 |
| --- | --- |
| 来源 | 阿里云 **DataV.GeoAtlas** 全国省级边界 `https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json` |
| 内容 | 34 个省级行政区（省 / 自治区 / 直辖市 / 特别行政区），台湾省、香港特别行政区、澳门特别行政区均作为省级单位完整绘制 |
| 加工 | ① 剔除南海断续线要素（adcode `100000_JD`），避免把主图纵向撑出大片空白；② 海南省要素原本包含三沙群岛（南至北纬 3.8°），主图中裁掉北纬 17° 以南的岛礁 |
| 坐标系 | 沿用数据源的经纬度坐标，由 ECharts 按经纬度直接投影，未做任何坐标转换或偏移处理 |

### 2. 南海诸岛断续线：ECharts 内置附图

主图数据本身**不含**九段线，图上的南海诸岛断续线由 **ECharts 内置的「南海诸岛」附图**绘制
（见 `echarts/lib/coord/geo/fix/nanhai.js`）。


### 合规说明

地图边界取自国内公开发布的标准行政区划底图数据，绘制时保证台湾省、香港特别行政区、澳门特别行政区
以及南海诸岛断续线完整呈现，不做任何缺省、简化或分离处理。
